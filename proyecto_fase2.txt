1.Resumen
El presente proyecto consiste en el desarrollo de un sistema avanzado para la gestión de un catálogo de productos de supermercado distribuido en múltiples sucursales interconectadas.
El sistema integra diversas estructuras de datos implementadas desde cero, tales como listas enlazadas, árboles (AVL, B y B+), tablas hash, colas y grafos, con el objetivo de optimizar las operaciones de almacenamiento, búsqueda y transferencia de productos.
Además, se incorpora la simulación del flujo de productos entre sucursales, considerando tiempos de procesamiento, despacho y costos de traslado, así como la medición de rendimiento de las distintas estructuras utilizadas.
El sistema permitirá visualizar tanto las estructuras internas como la red de sucursales, facilitando el análisis del comportamiento del sistema en diferentes escenarios.
2.Objetivo General
Desarrollar un sistema en C++ (o lenguaje seleccionado) que gestione de forma eficiente un catálogo de productos distribuido en una red de sucursales interconectadas, utilizando estructuras de datos avanzadas implementadas desde cero, permitiendo la búsqueda, almacenamiento, transferencia y simulación de productos, así como el análisis de rendimiento de las operaciones realizadas.

3.Objetivos específicos

a. Implementar desde cero las estructuras de datos requeridas (listas enlazadas, árboles AVL, árboles B y B+, tabla hash, colas y grafos).
b. Mantener la coherencia de los datos entre todas las estructuras al realizar operaciones de inserción, eliminación y actualización de productos.
c. Gestionar múltiples sucursales, cada una con su propio inventario de productos basado en las estructuras implementadas.
d. Implementar un grafo ponderado que represente la red de sucursales y sus conexiones, permitiendo calcular rutas óptimas de transferencia.
e. Simular el proceso de traslado de productos entre sucursales mediante el uso de colas, considerando tiempos de ingreso, preparación y despacho.
f. Permitir búsquedas eficientes de productos por diferentes criterios (nombre, código de barra, categoría y rango de fechas).
g. Medir y comparar el rendimiento de distintas estructuras de datos en operaciones de búsqueda, inserción y transferencia.
h. Implementar mecanismos de control como pilas para operaciones de deshacer (rollback) y manejo de errores.
i. Generar visualizaciones gráficas de las estructuras de datos y de la red de sucursales para facilitar el análisis del sistema.
j. Validar la carga de datos desde archivos CSV, manejando errores, duplicados y formatos incorrectos de manera robusta.

4.Descripción

El presente proyecto corresponde a la evolución del sistema de gestión de catálogo de productos desarrollado en la Fase 1, ampliándose hacia un modelo distribuido basado en múltiples sucursales interconectadas. Cada sucursal administra su propio inventario de productos utilizando estructuras de datos avanzadas implementadas desde cero, tales como listas enlazadas,
árboles AVL, árboles B, árboles B+ y tablas hash, garantizando operaciones eficientes de inserción, búsqueda y eliminación.
A diferencia de la fase anterior, donde el enfoque era un catálogo centralizado, en esta fase se introduce un modelo de red de sucursales representado mediante un grafo ponderado, donde cada nodo corresponde a una sucursal y cada arista representa una conexión con un peso asociado (tiempo o costo de traslado). Este modelo permite simular escenarios reales de distribución de productos, en los cuales un producto puede ser transferido desde una sucursal de origen hacia una sucursal destino a través de rutas óptimas calculadas mediante algoritmos de grafos.
El sistema deberá ser capaz de determinar dinámicamente la mejor ruta de transferencia de productos en función de criterios definidos por el usuario (mínimo tiempo o menor costo), considerando además sucursales intermedias cuando sea necesario. Durante este proceso, se simula el flujo de productos utilizando estructuras de colas, que representan las etapas de ingreso, preparación y despacho dentro de cada sucursal, respetando parámetros como tiempos de procesamiento e intervalos de envío.
Asimismo, el sistema incorpora mecanismos de control y consistencia de datos, asegurando que cada operación realizada sobre los productos se refleje correctamente en todas las estructuras involucradas. Se incluyen además estructuras auxiliares como pilas para la gestión de operaciones de deshacer (rollback) y control de cambios.

10. Búsqueda Avanzada

El usuario podrá realizar búsquedas por distintos criterios:
 Por nombre.  Por código de barras.  Por categoría.  Por rango de fechas.

12. Sistema de Despacho
Cuando un producto debe trasladarse de una sucursal a otra, el sistema determinará la ruta más eficiente según el criterio elegido (tiempo o costo). Cada sucursal involucrada podrá gestionar los productos mediante tres colas, como se describe a continuación:
1.Cola de ingreso:
a. Aquí llegan los productos recién recibidos. b. Si la sucursal es el destino final, el producto permanece aquí
después de ser procesado.
2.Cola de preparación de traspaso:
a. Aplica solo si la sucursal es intermedia. b. Los productos que deben continuar hacia otra sucursal se
colocan aquí mientras se preparan para el envío.
3.Cola de salida:
a. Contiene todos los productos listos para ser enviados desde la sucursal.

 Peso o costo de la conexión entre sucursales (tiempo o costo).
